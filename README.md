# Дешёвые цены — агрегатор цен на продукты для Ташкента

Сервис сравнения цен на продукты в Ташкенте (аналог arzan.kz для Казахстана):
собираем цены из каталогов магазинов, сопоставляем одинаковые товары между
магазинами и показываем, где дешевле и сколько можно сэкономить.

Статус: **ранний этап (proof-of-concept).** Проверяем доступность данных и
собираем первые сборщики цен.

---

## Что уже проверено (feasibility, 2026-08-10)

| Магазин   | Как отдаёт данные | Доступ | Итог |
|-----------|-------------------|--------|------|
| **Korzinka** | Чистый публичный JSON-API: `GET catalog.korzinka.uz/api/catalogs/categories` | Без авторизации, без блокировки Cloudflare | ✅ Собираем напрямую |
| **Makro** | Next.js, бэкенд `api.makromarket.uz`, ~305 товаров с ценами на странице каталога | Данные в разметке страницы | ✅ Достаётся (эндпоинт уточняем) |

Вывод: **данные доступны и структурированы — фундамент под проект есть.**
Ограничение: у Korzinka стоит лимит запросов на картинки (HTTP 429) — решается
паузами между запросами и собственным кэшем изображений.

Следующие источники к подключению: Uzum Market, Yandex Lavka/Eats, Havas, Carrefour.

---

## Как это устроено (модель, по образцу arzan.kz)

1. **Сбор** — по каждому магазину свой сборщик (`scrapers/`), приводит товары к
   единому формату (общая схема продукта).
2. **Сопоставление** — склеиваем один и тот же товар из разных магазинов
   (по штрих-коду `vendor_code`, а дальше по названию/бренду + ИИ). *(следующий этап)*
3. **Витрина** — поиск и карточка «где дешевле / сколько экономишь». *(следующий этап)*

### Общая схема товара

Каждый сборщик выдаёт записи такого вида:

```json
{
  "source": "korzinka",
  "source_product_id": 105963,
  "title_ru": "Виноград Шохона Узб. вес",
  "title_uz": "Uzum Shohona Oʻzb, kg",
  "vendor_code": null,
  "category": "Супер цены недели",
  "price": 19990,
  "old_price": 29990,
  "discount_percent": 33,
  "unit": "1кг",
  "image_url": "https://catalog.korzinka.uz/...",
  "currency": "UZS",
  "city": "Tashkent",
  "scraped_at": "2026-08-10T09:00:00+00:00"
}
```

## Технологии

- **Python** — сбор данных и (в будущем) сопоставление товаров.
- Пока используется только стандартная библиотека, ставить ничего не нужно.

## Как запустить сборщик Korzinka

```bash
python3 -m scrapers.korzinka
```

Результат сохраняется в `data/korzinka_sample.json` (папка `data/` не попадает в git).

## Структура

```
scrapers/
  common.py     — общие помощники (запрос, парсинг цены, сохранение)
  korzinka.py   — сборщик Korzinka (рабочий)
data/           — выгрузки (в git не хранятся)
```
