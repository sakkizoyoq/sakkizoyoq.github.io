# Дешёвые цены — агрегатор цен на продукты для Ташкента

Сервис сравнения цен на продукты в Ташкенте (аналог arzan.kz для Казахстана):
собираем цены из каталогов магазинов, сопоставляем одинаковые товары между
магазинами и показываем, где дешевле и сколько можно сэкономить.

Статус: **ранний этап (proof-of-concept).** Проверяем доступность данных и
собираем первые сборщики цен.

---

## Что уже проверено (feasibility, 2026-08-10)

| Магазин   | Как отдаёт данные | Доступ | Итог |
|-----------|-------------------|--------|------|
| **Korzinka** | Публичный JSON-API: `GET catalog.korzinka.uz/api/catalogs/categories` | Без авторизации | ✅ 322 акционных товара |
| **Makro** | Публичный JSON-API: `GET api.makromarket.uz/api/v2/product-list/` | Без авторизации | ✅ 305 товаров, ru + uz, с датами акций |
| **Uzum Market** | GraphQL `graphql.uzum.uz`, операция `MakeSearch_ItemsAndFilters` | Нужен гостевой пропуск (живёт ~3 часа) | ✅ Полный ассортимент, поиск |
| **Яндекс Еда** | `POST eats.yandex.com/api/v2/menu/goods` c `{"slug": "..."}` | Без авторизации и без адреса доставки | ✅ Полные каталоги: Makro 3047, Safia 257 |

Вывод: **данные доступны и структурированы — фундамент под проект есть.**
Ограничение: у Korzinka стоит лимит запросов на картинки (HTTP 429) — решается
паузами между запросами и собственным кэшем изображений.

Следующие источники к подключению: Uzum Market, Yandex Lavka/Eats, Havas, Carrefour.

## Как это устроено

1. **Сбор** — по каждому магазину свой сборщик (`scrapers/`), приводит товары к
   единому формату (общая схема продукта).
2. **Сопоставление** (`matching.py`) — склеивает один и тот же товар из разных
   магазинов по названию: сверяет размер, упаковку, артикул, бренд, процент и
   номер ступени. Штрих-кодов магазины не отдают, поэтому решение принимается по
   названию — и намеренно строго.
   Отдельно (`translit.py`) — сведение русских и латинских написаний: Яндекс Еда
   пишет «Pyure rastishka yabloko grusha», а Korzinka — «Пюре Растишка яблоко
   груша». Оба варианта приводятся к общему «скелету» слова.
3. **Витрина** (`site/`) — поиск, карточки «где дешевле», цена за кг/литр.

### Порядок запуска

```bash
python3 -m scrapers.korzinka      # акции Korzinka
python3 -m scrapers.makro         # акции Makro
python3 -m scrapers.yandex_eats   # полные каталоги Makro и Safia из Яндекс Еды
python3 -m scrapers.uzum          # каталог Uzum (нужен свежий UZUM_TOKEN)
python3 build_comparisons.py      # найти одинаковые товары → data/comparisons.json
python3 build_site.py             # собрать страницу → site/index.html
```

> **Про пропуск Uzum.** Гостевой токен живёт ~3 часа. Взять свежий: открыть
> uzum.uz, в консоли браузера `localStorage.getItem('auth_sdk_access_token')`,
> затем запускать с `UZUM_TOKEN="eyJ..." python3 ...`. Автоматизация — этап 2 плана.

### Общая схема товара

Каждый сборщик выдаёт записи такого вида:

```json
{
  "source": "korzinka",
  "source_product_id": 105963,
  "title_ru": "Виноград Шохона Узб. вес",
  "title_uz": "Uzum Shohona Oʻzb, kg",
  "vendor_code": null,
  "category": "Супер цены недели",
  "price": 19990,
  "old_price": 29990,
  "discount_percent": 33,
  "unit": "1кг",
  "image_url": "https://catalog.korzinka.uz/...",
  "currency": "UZS",
  "city": "Tashkent",
  "scraped_at": "2026-08-10T09:00:00+00:00"
}
```

## Технологии

- **Python** — сбор данных и (в будущем) сопоставление товаров.
- Пока используется только стандартная библиотека, ставить ничего не нужно.

## Как запустить сборщик Korzinka

```bash
python3 -m scrapers.korzinka
```

Результат сохраняется в `data/korzinka_sample.json` (папка `data/` не попадает в git).

## Структура

```
scrapers/
  common.py       — общие помощники (запрос, разбор цены, сохранение)
  korzinka.py     — сборщик Korzinka
  makro.py        — сборщик Makro
  uzum.py         — сборщик Uzum Market (GraphQL)
  yandex_eats.py  — сборщик Яндекс Еды (полные каталоги магазинов)
matching.py       — движок сопоставления товаров + цена за кг/литр
translit.py       — сведение русских и латинских написаний
build_comparisons.py — ищет одинаковые товары в разных магазинах
build_site.py     — собирает страницу витрины (с кэшем картинок)
site/             — витрина
data/             — выгрузки и кэш (в git не хранятся)
ПЛАН.md           — план работы по этапам
```

## Демо-витрина (site/)

Первая рабочая витрина на **реальных ценах** Ташкента: поиск, блок «Сравнение цен»
(один товар — цены в разных магазинах, дешёвый подсвечен) и сетка товаров Uzum
со скидками. Рабочее название бренда — **sakkizoyoq** (осьминог).

- `site/index.template.html` — вёрстка страницы (плейсхолдер `__DATA__` вместо данных).
- `site/index.html` — собранная страница с встроенными данными и картинками (генерируется).
- Данные берутся из `data/uzum_sample.json` + `data/korzinka_sample.json`; пары для
  сравнения проверены вручную и лежат в `data/demo.json`, картинки встраиваются как data-URI.

Открыть локально:

```bash
cd site && python3 -m http.server 8778
```

и зайти на http://localhost:8778/index.html
