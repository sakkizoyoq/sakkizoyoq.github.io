Сравнение появляется только там, где один и тот же товар нашёлся минимум в двух источниках. Ниже — весь список целиком, с ценами и переходами в магазин.

Собираем цены

Четыре источника, у каждого свой характер: у одних только акции, у других весь каталог.

2

Ищем один и тот же товар

Программа сверяет бренд, объём и упаковку. Спорные пары отбрасывает — лучше меньше, чем ошибка.

3

Остаётся пересечение

Товар попадает в сравнение, только если он есть минимум в двух источниках сразу.
